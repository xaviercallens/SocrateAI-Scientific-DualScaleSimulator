## 2. Results per round

### Round 1 forward (hypothesis -> experiment -> TDA -> reduce)

Positive
- Sweep: 421/421 points completed, 316 numerically stable (`param_sweep.py` -> `sweep.csv`).
- Real data used: DESI 2024 BAO (12 points, full 12x12 covariance) + Pantheon+ Hubble-flow subset (N=1590, diagonal errors). sha256 of all fetched files verified.
- Model best fit: chi2 = 703.88 (dof 1596), at a_pot=3.471, b_pot=4.28e-4 (`chi2_report.json`).
- Response rank (Jacobian SVD) at best fit: singular values [4.65, 2.58, 1.72, 3.7e-4, 3.2e-14, 0.0], effective dimension 3 (`jacobian_report.json`). Two exact null directions at all 6 probed points: the pta/c4 split and lambda_sym.
- GUDHI 3.13 known-answer control passed: noisy circle gives one dominant H1 bar, persistence ratio 62.9 (`tda_report.json`).
- Harness negative controls closed (commit 88f7a51): mutations that break the mu_sym or PTA dependence now make the selftest fail.

Negative
- Flat LCDM: chi2 = 697.34 (dof 1598). LCDM wins by delta chi2 = 6.54 with one parameter fewer.
- Best-fit w(z) at the six z-points is [-0.469, -0.586, -0.221, -0.680, +0.043, +0.467] (skeptic re-run): an oscillating field, so the quoted CPL summary (w0, wa) = (-0.694, 0.955) is a poor description.

- 105/421 sweep points (25%) numerically unstable (mu_sym divergence zone).
- TDA: model cloud, Pantheon+ residual cloud, 2MRS patch, and the null all have Betti [1,0]. No discriminating power. The 2MRS cloud is RA/Dec only (no redshift), so it is not a comoving embedding.
- Two bugs found and fixed in-round (SN distance-modulus interpolation near z=0; BAO nuisance search clipping at its bound).

## 3. What the reverse loop says about the hypothesis

1. **The data cannot see most of the theory.** About 3 directions are resolvable; `lambda_sym` and `c4_pta_product` sit in null directions in both passes. "Invisible to current data" is not "derived", so this does not reduce the count.
2. **The dark-energy sector is mis-built for this question.** In the toy model `(a_pot, b_pot)` jointly set w(z) AND the effective matter fraction, through the a0 = a(t_max) normalisation. So w cannot be pinned without also changing Omega_m. The claim "w0=-1, wa=0 is rejected by BAO+SN at delta chi2 = +5780" is invalid: that point has no matter. Flat LCDM has w0=-1, wa=0 exactly and is the best fit in the study.
3. **The data do not ask for the quintessence sector.** LCDM wins by 8.54 AIC units. Support in the fetched data for a DESI-style w0-wa preference is ABSENT (no CPL fit was run).
4. **The only observably alive non-LCDM sector, `mu_sym` (screening), has never met real data.** Fifth-force data: ABSENT.
5. **TDA is a sanity gate here, not evidence.** It should stay in the loop only with its controls.
